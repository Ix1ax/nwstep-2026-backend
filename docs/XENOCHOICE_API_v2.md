## 1. Концепция и трехуровневая модель (ТЗ v2)

В соответствии с уточненным ТЗ v2 система разделена на три строгих физических уровня:

1. **Планета (World)** — физическая среда (небесное тело). Не является организмом, не размножается и не умирает. Служит источником внешних градиентов энергии и шума.
2. **Особь (Individual)** — гипотетическая небиологическая структура (узел), расположенная на сфере $(\text{lat}, \text{lng})$. Обладает запасом энергии, структурным ресурсом (биомассой), динамической памятью, геномом и механизмом выбора действий.
3. **Колония (Colony)** — сообщество взаимодействующих особей на планете. Агрегирует показатели своих участников (численность, суммарная энергия, уровень связности, распределение решений) и способна образовывать дочерние колонии при почковании связных групп.

## 2. Физические модули сред (Планеты)

Справочные физические параметры взяты из официальных данных **NASA Planetary Fact Sheet** (версия от 18.03.2025):

| Планета | Ср. температура | Гравитация | Давление | Источник данных |
|---|---|---|---|---|
| **Земля** (`earth`) | +15 °C (288.15 K) | 9.8 м/с² | 1.0 бар | NASA Planetary Fact Sheet |
| **Марс** (`mars`) | −65 °C (208.15 K) | 3.7 м/с² | 0.01 бар | NASA Planetary Fact Sheet |
| **Венера** (`venus`) | +464 °C (737.15 K) | 8.9 м/с² | 92.0 бар | NASA Planetary Fact Sheet |

### 2.1. Земля — минеральные проводящие структуры
- **Модель**: Внешний электрический потенциал $V_{\text{ext}}$ питает сеть емкостных накопителей заряда.
- **Внутренний потенциал**: $V = \sqrt{\frac{2E}{C}}$, где $C = 2.0\text{ Ф}$.
- **Ток и приток мощности**: $I = G \cdot \max(0, V_{\text{ext}} - V_i)$, $P = I \cdot V_{\text{ext}}$.
- **Потери в каналах**: Омические потери, возрастающие с расстоянием на сфере: $\text{Loss} = \min(0.9, 0.05 + 0.5 \cdot \text{dist}_{\text{rad}})$.

### 2.2. Марс — пылевые резонаторы
- **Модель**: Захват трибоэлектрических микроимпульсов от движения пылевых частиц в разреженной атмосфере.
- **Приток мощности**: $P = \text{dustIntensity} \cdot \text{stormFactor} \cdot \text{circulation} \cdot P_{\text{base}} \cdot (1 + \text{noise})$.
- **Буря**: Вмешательство `perturbation` увеличивает шум в 3.5 раза и повышает абразивный износ структур (увеличение затрат на поддержание).
- **Потери в каналах**: $\text{Loss} = \min(0.9, 0.08 \cdot \text{stormFactor} + 0.7 \cdot \text{dist}_{\text{rad}})$.

### 2.3. Венера — тепловые структуры
- **Модель**: Вертикальный тепловой поток в сверхплотной атмосфере (92 бар) между горячей поверхностью ($T_h \approx 750\text{ K}$) и верхним слоем ($T_c \approx 710\text{ K}$).
- **Тепловой поток**: $\dot{Q} = k \cdot A \cdot \frac{\Delta T}{L}$.
- **Предел Карно**: Полезная работа строго ограничена термодинамическим пределом:
  $$\eta_{\text{carnot}} \le 1 - \frac{T_c}{T_h} \approx 0.053\text{ (5.3\%)}, \quad W = \eta_{\text{carnot}} \cdot \dot{Q} \cdot dt$$
- **Затраты**: Высокие затраты на сброс энтропии и охлаждение структур в агрессивной среде.

## 3. Целевая функция выбора действий (Раздел 7.3 ТЗ v2)

На каждом такте каждая живая особь рассчитывает безразмерную целевую оценку для 4 альтернатив:

$$score(a) = w_E \cdot \text{expectedReserve} - w_D \cdot \text{expectedDeficit} + w_C \cdot \text{neighborRelief} + w_R \cdot \text{reproductionResult} - w_{\text{Cost}} \cdot \text{irreversibleCost}$$

Веса неотрицательны и нормированы: $\sum w_i = 1$.

### Допустимые действия:
1. `STORE`: Сохранение энергии во внутреннем аккумуляторе. Всегда доступно.
2. `TRANSFER`: Физическая передача ресурса по каналу связи соседу, испытывающему дефицит.
3. `GROW`: Конверсия накопленной энергии в структурный ресурс (биомассу) с коэффициентом эффективности $\eta_{\text{growth}} = 0.8$.
4. `DIVIDE`: Деление особи при накоплении $B \ge B_{\text{split}} = 20\text{ BU}$ и наличии достаточного запаса энергии на стартовый капитал потомка и стоимость деления.

### Режимы принятия решений:
- **Реактивный (`reactive`)**: Автомат «стимул — ответ» по текущему запасу энергии без учета динамической памяти.
- **Адаптивный (`adaptive`)**: Учет динамической памяти $M_{t} = \lambda M_{t-1} + (1 - \lambda) \cdot \text{netInflow}$. При устойчивом дефиците ($M < 0$) особь повышает веса самосохранения ($w_D, w_E$) и сокращает траты на кооперацию.
- **Эволюционный (`evolutionary`)**: Индивидуальный геном $(w_E, w_D, w_C, w_R, w_{\text{Cost}}, \lambda, h)$, наследуемый потомками с вероятностью мутации $10\%$ и амплитудой $\pm 5\%$.

## 4. Спецификация REST API v2 (`/api/v2/...`)

### 4.1. Каталог планет
#### `GET /api/v2/worlds`
Возвращает список доступных миров, их справочные параметры NASA, локальные сценарии и конфигурации модели.

**Пример ответа**:
```json
{
  "success": true,
  "data": [
    {
      "id": "earth",
      "name": "Земля",
      "description": "Минеральные проводящие структуры в локальном электрическом градиенте",
      "reference": {
        "bodyName": "Earth",
        "meanTemperatureCelsius": 15,
        "temperatureKelvin": 288.15,
        "gravity": 9.8,
        "surfacePressureBar": 1,
        "source": "NASA Planetary Fact Sheet",
        "sourceDate": "2025-03-18"

      "scenario": {
        "regionName": "Геотермально-минеральный разлом",
        "baseFlow": 10,
        "noiseAmplitude": 0.1,
        "specificParams": {
          "capacitance": 2,
          "electricGradient": 5
        }
      }
    }
  ]

```

### 4.2. Управление экспериментами

#### `POST /api/v2/experiments`
Создает новый детерминированный эксперимент на выбранной планете.

**Тело запроса**:
```json
{
  "name": "Исследование адаптации на Марсе",
  "worldId": "mars",
  "mode": "adaptive",
  "seed": 42
}
```

**Ответ**: `201 Created` с объектом эксперимента и начальным снимком состояния.

---

#### `GET /api/v2/experiments`
Возвращает список всех активных экспериментов в памяти.

#### `POST /api/v2/experiments/:id/commands`
Выполняет команду управления симуляцией.

**Поддерживаемые команды**:
- `"start"` — запуск цикла симуляции.
- `"pause"` — приостановка.
- `"resume"` — возобновление.
- `"step"` — выполнение ровно одного такта.
- `"setSpeed"` — установка множителя скорости (`speed: 1`, `2` или `5`).

**Тело запроса**:
```json
{
  "commandId": "cmd-001",
  "command": "step",
  "expectedRevision": 120
}
```

---

#### `POST /api/v2/experiments/:id/interventions`
Внесение внешнего воздействия исследователя (раздел 8 ТЗ v2).

**Типы воздействий**:
- `add_inoculum`: Внесение первичных зародышей в указанные координаты.
- `set_flow`: Изменение базового притока энергии.
- `set_noise`: Изменение амплитуды флуктуаций.
- `impulse`: Временный импульс притока энергии.
- `perturbation`: Внешнее возмущение (буря на Марсе / волна давления на Венере).
- `depletion`: Временное отключение притока (проверка выживания при истощении).
- `toggle_mutations`: Включение/выключение мутаций генома (`value: 1.0` или `0.0`).

**Пример запроса**:
```json
{
  "tick": 150,
  "sequence": 0,
  "type": "perturbation",
  "targetId": "mars",
  "value": 3.0
}
```

---

#### `GET /api/v2/experiments/:id/colonies/:colonyId`
Возвращает подробную информацию о выбранном сообществе, его родительской колонии и список входящих в него особей.

---

#### `GET /api/v2/experiments/:id/individuals/:individualId`
Возвращает полную трассировку состояния особи, координаты на сфере, геном, память и последнее принятое решение с оценками всех альтернатив.

---

#### `GET /api/v2/experiments/:id/metrics?from=0&to=500`
Возвращает историю метрик прогона (популяция, энтропия, эффективность, энергобаланс).

---

#### `GET /api/v2/experiments/:id/export?format=json` (или `format=csv`)
Экспортирует результаты эксперимента:
- `format=json`: Полный канонический бандл эксперимента (схема v2.0).
- `format=csv`: Табличный файл временных рядов метрик согласно разделу 14 ТЗ v2.

---

#### `POST /api/v2/experiments/import`
Импортирует ранее экспортированный JSON-бандл эксперимента.

---

#### `POST /api/v2/experiments/:id/replay`
Воспроизводит эксперимент от такта 0 до указанного `targetTick` с тем же seed и журналом воздействий, гарантируя 100% совпадение контрольной суммы SHA-256.

**Тело запроса**:
```json
{
  "targetTick": 100
}
```

## 5. WebSocket API v2 (`/api/v2/experiments/:id/stream`)

Обеспечивает стриминг обновлений состояния в реальном времени с частотой до 10 Гц.

### 5.1. Формат входящих сообщений (сервер -> клиент)
```json
{
  "type": "snapshot",
  "experimentId": "exp-a1b2c3d4",
  "worldId": "earth",
  "tick": 45,
  "revision": 46,
  "payload": {
    "tick": 45,
    "individuals": [...],
    "colonies": [...],
    "channels": [...],
    "inTransit": [...],
    "signals": [...],
    "metrics": { ... }
  }
}
```

### 5.2. Управление через WebSocket (клиент -> сервер)
Клиент может отправлять команды напрямую через сокет:
```json
{
  "command": "setSpeed",
  "speed": 2
}
```

## 6. Закон сохранения энергии и детерминизм

На каждом такте верифицируется инвариант сохранения энергии:

$$E_{\text{initial}} + E_{\text{inoculated}} + E_{\text{external}} = E_{\text{current}} + E_{\text{inTransit}} + E_{\text{maintenance}} + E_{\text{signaling}} + E_{\text{channelLoss}} + E_{\text{conversionLoss}} + E_{\text{divisionCost}} + E_{\text{overflow}} + E_{\text{deathDissipation}}$$

Невязка баланса строго ограничена:
$$\Delta = |E_{\text{input\_total}} - E_{\text{expenditure\_total}}| < 10^{-6}\text{ BU}$$

Все обходы структур в движке выполняются в строго детерминированном порядке сортировки идентификаторов, исключая псевдослучайные эффекты порядка обхода структур данных в памяти.
